# SQL Practice for Data Engineering

This repository contains my **SQL practice projects** focused on **Data Engineering**, including retail-based exercises and star schema dimensional modeling. The exercises cover a wide range of SQL concepts from basic queries to advanced transformations and window functions.

---

## ** 1. Retail Practice (Data Engineering)**

This section focuses on retail data engineering exercises. The files included are:

| File | Description |
|------|-------------|
| `CTE.sql` | Practice on Common Table Expressions (CTEs) for intermediate queries. |
| `Joins.sql` | Examples of INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL OUTER JOIN. |
| `aggregation_operations.sql` | Practice on aggregation functions like SUM, COUNT, AVG, MIN, MAX. |
| `createTables.sql` | Scripts to create tables for retail practice datasets. |
| `filter data using aggregation and group_by and having.sql` | Filtering aggregated data using GROUP BY and HAVING clauses. |
| `filter_operations.sql` | WHERE clause and other filtering operations. |
| `group_operations.sql` | Grouping data using GROUP BY with different aggregations. |
| `order of sql syntax and execution.sql` | Understanding the SQL query execution order. |
| `views.sql` | Creating and using views to simplify queries. |

---

## ** 2. Star Schema & Dimension Practice**

This section focuses on **star schema dimensional modeling** and related SQL operations. The files included are:

| File | Description |
|------|-------------|
| `CTE's.sql` | Using Common Table Expressions for star schema queries. |
| `basics and aggregations.sql` | Basic SQL operations with aggregation in dimensional tables. |
| `conditions.sql` | Applying conditions and filters in star schema queries. |
| `source_setup.sql` | Setting up source tables for dimensional modeling practice. |
| `sub queries.sql` | Writing nested queries and subqueries. |
| `transformations.sql` | Data transformation exercises. |
| `views.sql` | Creating and using views for star schema queries. |
| `window functions.sql` | Practice on window functions such as ROW_NUMBER, RANK, and SUM OVER(). |

## **Skills Practiced**

- SQL querying fundamentals: SELECT, WHERE, GROUP BY, HAVING, ORDER BY  
- Joins: INNER, LEFT, RIGHT, FULL OUTER  
- CTEs and subqueries  
- Aggregations and transformations  
- Views creation and usage  
- Window functions and analytics queries  
- Understanding query execution order  
- Data modeling for **star schema** and dimensional analysis  

---

## **Goal**

The purpose of these exercises is to **strengthen SQL skills for Data Engineering** use cases, such as:

- Data analysis on retail datasets  
- Transformations and aggregations for analytics  
- Creating reusable queries using views and CTEs  
- Working with star schema data models and performing dimensional queries
